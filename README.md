# Ai - Hindi Dubbed Anime Website

This is a simple anime website called **Ai** where users can watch Hindi dubbed anime episodes.

## Features
- Homepage with anime list
- Each anime has its own episode list
- Google Drive links for all episodes
- Mobile-friendly design

## How to Use
Visit the website here: [https://aianimehub.github.io/Ai/](https://aianimehub.github.io/Ai/)
